# 古籍数学化与计算流程方案

更新日期：2026-08-02

> 回答三个问题：计算流程如何整理、公式如何定义、每本书能否数学化。
> 结论：**能，但要分级**。数学化的产出是"特征 + 可检验假设"，不是"预测打分函数"——
> 任何古籍都没有给出把全书规则聚合成一个分数的权重，发明权重就是发明古籍里没有的东西。

## 一、统一计算流程（五级流水线）

```text
(1) 排盘 C：出生时刻 t、经纬度 loc、性别 sex、排盘配置 config
      C(t, loc, sex, config) → 命盘 S          # engines/bazi.py，已实现
(2) 基础映射表：藏干、十神、合冲刑害、长生、纳音、神煞
      canon/tables/*.yaml                        # 纯查表，无自由参数
(3) 特征函数 Φ：Φ(S) → 特征向量 x
      x = (十神分布, 格局, 旺衰强度, 调候需求, 神煞命中, …)
(4) 规则求值 E：对每条规则 r ∈ R_school，E(r, x) ∈ {0, 1}（是否命中）
      canon/engine.py 解释执行 YAML；输出 data/features/<school>.parquet
      每列 = 一条规则的命中指示变量，携带 rule_id 可回查原文
(5) 统计层：规则指示变量 → Y 域的关联检验
      analysis/*；聚合模型（如 logistic）的权重由数据估计并预注册，
      不属于古籍数学化的一部分
```

关键分界线：**(1)–(4) 是确定性的、无参数或参数已声明的；(5) 才允许估计参数。**
把这条线画清楚，"古籍说了什么"和"数据说了什么"就不会互相污染。

## 二、公式定义规范（形式化原语）

### 2.1 基础集合与映射

```text
天干  G = {甲,乙,丙,丁,戊,己,庚,辛,壬,癸}         |G| = 10
地支  Z = {子,丑,寅,卯,辰,巳,午,未,申,酉,戌,亥}    |Z| = 12
五行  W = {木,火,土,金,水}；阴阳 P = {阳,阴}

elem : G∪Z → W          # 干支五行属性（查表）
pol  : G → P             # 天干阴阳（查表）
hidden : Z → [(G, w)]    # 藏干及权重，w 为方案参数（equal / 本气中气余气加权）
rel  : W × W → {生,克,同,被生,被克}                # 五行生克（循环序）
```

### 2.2 十神（全部规则的公共坐标系）

对日主 d ∈ G、任意干 g ∈ G：

```text
十神(g | d) = σ( rel(elem(d), elem(g)), pol(d) == pol(g) )
```

σ 是 5×2 的确定映射：同我(同性=比肩/异性=劫财)、我生(食神/伤官)、
我克(偏财/正财)、克我(七杀/正官)、生我(偏印/正印)。**无自由参数。**

### 2.3 命盘与特征

```text
命盘 S = ((g₁,z₁),(g₂,z₂),(g₃,z₃),(g₄,z₄), 大运序列, 流年序列)
        # 年月日时四柱；d := g₃（日主）

示例特征：
  月令十神    m(S)   = 十神( 主气(hidden(z₂)) | d )
  透干集合    T(S)   = { 十神(gᵢ|d) : i∈{1,2,4} }
  旺衰强度    Str(S) = Σ_pos w_pos · Σ_{(g,w)∈hidden(z_pos)} w · I[rel ∈ {同,被生}]
                       # w_pos（宫位权重）与藏干权重是自由参数 → 见第四节
  调候需求    QT(S)  = LUT_穷通[z₂][d]              # 120 格查表，无参数
```

### 2.4 规则的统一形式

每条规则是一个三元组，YAML 即其序列化（schema 见实施计划 P2.5）：

```text
r = ( φ_r, y_r, dir_r )
  φ_r  : 特征向量上的一阶谓词（原子谓词的合取/析取/否定）
  y_r  : 断言指向的 Y 域（career / lifespan / …）
  dir_r: 方向（偏多 / 偏少 / HR<1 / …）

原子谓词只允许取自封闭词表：
  eq(月令十神, 正官) / has(透干, 正财) / clash(z₂, z_any) /
  in_range(Str, θ₁, θ₂) / lut(穷通, z₂, d) == 丙 / …
```

规则冲突不消解：同书冲突用 `priority`/`override`（对应"因成得败/因败得成"），
书间冲突分属不同 `school`，各自独立出特征列。

## 三、数学化分级（T1–T4）

| 级 | 数学对象 | 含义 | 验证可行性 |
|---|---|---|---|
| **T1 查表型** | 有限映射 LUT | 条件与结论都是枚举，原文即真值表 | 立即可做，零歧义 |
| **T2 谓词型** | 布尔规则链 + override | 条件可写成封闭词表谓词 | 可做，需校勘定分支 |
| **T3 参数型** | 加权和 / 阈值判断 | 概念可算，但权重阈值原文没给数值 | 可做，参数须登记为超参数空间并做敏感性分析，禁止用结果数据调参后再当"古籍原意" |
| **T4 意象型** | 无 | "清浊""有情""气势"等无操作化定义 | 挂起 `operational: false`，或明确标注"现代重构代理定义" |

## 四、逐书方案

### 4.1 八字类（X=出生时间，现有数据可验证）

| 书 | 主级 | 数学化方案 | 优先级 |
|---|---|---|---|
| **穷通宝鉴/造化元钥** | T1 | 12月支×10日干=120格调候用神查表；`LUT[z₂][d] → 用神干` | ★★★ 第一个做：无歧义、可整书数学化 |
| **子平真诠** | T2 | 取格三级回退链（月令→透干→会支）+ 成败布尔条件 + 救应 override | ★★★ 规则密度最高 |
| **命理约言** | T2 | 条文式，直接翻译为谓词规则 | ★★ |
| **神峰通考** | T2 | 病药模型：detect(病) → require(药)，双谓词对 | ★★ |
| **八字提要** | T1/T2 | 按日干×月令组织，接近查表 | ★★ |
| **千里命稿** | T2 | 规则少但**命例多且带答案**→ 转为引擎回归测试集 | ★★（做测试集） |
| **渊海子平** | T2+T4 | 继善篇等条文 T2；赋体部分 T4 挂起 | ★ |
| **三命通会** | T1+T2+T4 | 神煞表/纳音表 T1、格局论 T2、赋 T4；当规则候选库逐段捞 | ★（长期） |
| **滴天髓阐微** | T3+T4 | 旺衰/气势需定义 Str 函数（参数型）；清浊真假 T4 挂起；任氏命例→测试集 | ★ |
| **子平管见/呱呱集/御定子平/月谈赋/兰台妙选** | 混合 | 残本或小书，随主线补充；御定子平站点仅节选，需全本 | 低 |

### 4.2 古法禄命类（X=出生时间，但体系不同）

李虚中命书、玉照定真经、鬼谷遗文、珞琭子消息赋：以年柱、纳音为主。
纳音是 60→30 的确定查表（T1），规则多为赋体（T4）。方案：先建
`tables/nayin.yaml`，规则层只捞出可谓词化的少数条文，**作为与子平法的
历史对照流派**（`school: gufa`），不与日主派混合。

### 4.3 星命类（X 需扩展）

星平会海、星命总括、星命抉古录：需要七政四余星盘，排盘引擎要加
天文历算（如 swisseph）。规则谓词词表不同（宫位、星曜）。列为独立
工作包，暂不阻塞八字主线。

### 4.4 理论/占卜/体相类

- **五行大义**：理论书，无预测规则；作为 tables 层（生克、旺相休囚死）的文献依据。
- **易经/易传**：卦象数学化平凡（六爻 = 6 bit，2⁶=64 卦），但占卜验证属 P2 前瞻实验。
- **相学/风水**（待下载）：X 不可得，按 Y 域总表 4.8 节挂起，仅文献层。
- **称骨歌**：T1（年月日时四权重求和查等级表），规则极简 → 适合当**对照基线**：
  若复杂体系跑不赢称骨这种粗糙查表，说明复杂度没有带来信息。

## 五、忠实性验证：命例回归测试

数学化是否忠实于原书，有一个可测标准：**古籍自带命例**。
千里命稿、滴天髓阐微（任氏注）、神峰通考（张楠自注）都附有大量
"命盘 + 作者断语"。流程：

```text
命例(四柱, 原书结论) → 引擎复算(取格/用神/喜忌) → 与原书结论比对
```

写入 `tests/canon_cases/<book>.yaml`，每书抽 10–30 例。引擎与原书不一致
只有两种解释：规则提取错了，或原书自身不自洽——两种都值得记录（后者
本身就是研究发现）。这取代"感觉编码得对"，是 P2.5 验收标准的扩展。

## 六、执行顺序建议

1. `tables/`：藏干、十神、合冲刑害、长生、纳音（全体系共用，T1）
2. `qiongtong.yaml`：穷通宝鉴 120 格查表（第一个完整数学化的流派）
3. `ziping.yaml`：子平真诠取格链（T2，依赖校勘完成）
4. 千里命稿命例 → 回归测试集（验证 1–3）
5. `xuleiwu.yaml` + Str 函数（T3，参数空间登记进 `bazi_configs`）
6. 命理约言、神峰通考、八字提要（T2 扩充）
7. 古法/星命/占卜类按独立工作包排期
