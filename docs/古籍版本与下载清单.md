## 使用原则

本目录只保存可追溯的扫描本和开放网页文本，不把现代白话译本、商业注本或网络二次整理直接当作古籍原文。每条规则必须记录：书名、卷次、版本、馆藏来源、原始链接、文件 SHA-1 和原文位置。

本地文件位于 `data/raw/canon/wikimedia/`，数据目录不提交 git；本清单提交版本和哈希，保证之后可以重新下载和核验。

## 版本学上的限制

1. **书名不等于单一文本**：同名书可能有不同卷数、增补、评注和坊刻本。
2. **后世评注不能冒充原文**：例如“评注”“阐微”“本义”必须拆成独立层，不能直接写入古籍规则。
3. **作者和年代有争议时保留争议**：不把传统托名自动当作确定作者；数据字段应有 `author_claimed`、`author_status`、`date_claimed`。
4. **扫描本与录入本要对校**：录入文字用于搜索，扫描页才是版本核验依据；关键规则至少回看扫描页。
5. **公有领域不代表没有来源义务**：保留馆藏、扫描平台、原始文件名和哈希；若未来分发 OCR 文本，仍要附来源和许可证说明。

## 后续提取顺序

第一批不直接把整本书交给模型总结，而是按主题人工定位并保存短引文：

1. 月令、用神、格局成败；
2. 五行生克、旺衰、调候；
3. 大运、流年、应期；
4. 官禄、财、婚姻、子女、疾病、寿命等传统预测对象；
5. 神煞、纳音、胎元等附加体系。

每条原文记录至少包含：`source_id`、`book`、`edition`、`volume`、`chapter`、`page`、`quote`、`modern_interpretation`、`operational_y`、`rule_status`。未经人工核对的内容只能标记为候选规则，不能进入预注册假设。
