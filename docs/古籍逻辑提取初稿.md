## 一、先统一输入

```text
出生年、月、日、时、性别、出生地点（经纬度）
→ 历法转换（含节气精确时刻）
→ 真太阳时校正、早晚子时归属（sect 配置）
→ 四柱干支
→ 日主、月令、五行强弱、十神、合冲刑害
→ 用神/格局候选
→ 大运（顺逆排依赖性别：阳年男/阴年女顺排，否则逆排；起运岁数依赖节气时刻）、流年
→ 预测域 Y
```

性别与经纬度是必需输入：缺性别无法排大运，缺经纬度无法做真太阳时校正（时柱可能错位）。
排盘变体（真太阳时开关 × sect）由 P1 的 `bazi_configs` 承载，规则本身不感知配置。

项目中的 Y 暂定为：婚姻、职业、教育、财富、健康、家庭、迁移、成就、法律、寿命等事件域。

## 二、《子平真诠》：月令—用神—格局—行运

来源：本地 [现代网页文本](../data/processed/canon/ziping_zhenquan_online.txt)（**徐乐吾评注本**）；扫描本需进一步核对。
引用锚定用篇名 + 原文引文，不用网页版章节号。

**本节分两层，对应两个独立流派文件，不得混用**：

- 层 A（原文，沈孝瞻）→ `ziping.yaml`：月令取格、顺逆用；
- 层 B（徐注）→ `xuleiwu.yaml`：扶抑/病药/调候/专旺/通关五用神。

### 1a. 取用神 —— 层 A：原著月令取格（text_layer: 原文）

> 锚定引文（论用神）：“八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉。
> 财官印食，此用神之善而顺用之者也；煞伤劫刃，用神之不善而逆用之者也。当顺而顺，当逆而逆，配合得宜，皆为贵格。”

| 条件 | 简化逻辑 |
|---|---|
| 任何命盘 | 用神专求月令：以日干配月令地支定格局，不先逐字独立判断 |
| 月令为财、官、印、食（四吉神） | 顺用：生之护之（细则见 1c） |
| 月令为煞、伤、劫、刃（四凶神） | 逆用：制之化之（细则见 1c） |
| 月令为禄劫印绶而日元盛旺、劫印不可用 | 于年日时干支中别求克泄之神，但关键仍在月令 |

### 1b. 取用神 —— 层 B：徐注五用神（text_layer: 评注）

> 锚定引文（论用神·徐注）：“取用之法不一，约略归纳，可分为下列五种”（扶抑、病药、调候、专旺、通关）。

| 条件 | 简化逻辑 |
|---|---|
| 日主过强 | 扶抑：优先找能克制或泄耗日主的因素 |
| 日主过弱 | 扶抑：优先找能生扶或帮助日主的因素 |
| 局中存在明显破坏项 | 病药：找能去掉该破坏项的因素 |
| 夏季过热、冬季过寒 | 调候：先找调节寒暖燥湿的因素 |
| 五行力量极端且难以逆转 | 专旺：顺着主要气势取用，不强行反制 |
| 两种力量相持 | 通关：找第三种力量疏通双方 |

### 1c. 顺逆用细则 —— 层 A（text_layer: 原文）

> 锚定引文（论用神）：“是以善而顺用之，则财喜食神以相生，生官以护财；官喜透财以相生，生印以护官；
> 印喜官煞以相生，劫财以护印；食喜身旺以相生，生财以护食。不善而逆用之，则七煞喜食神以制伏，忌财印以资扶；伤官喜佩印……”

### 2. 评价格局（text_layer: 原文）

```text
月令确定主要格局
→ 查看是否有支持链
→ 查看是否有冲克、合化、夺用
→ 判断：成立 / 破坏 / 有救应（因成得败 / 因败得成 作为 override 层）
```

简化规则（`operational` 标注该条是否已可机器执行）：

- 正官：有财生官、印护官，且没有严重冲克，格局较完整；`operational: true`
- 财：有食神生财、身能任财，且比劫不夺财，格局较完整；`operational: true`
- 印：有官杀生印，或身强印旺时有食伤泄身，格局较完整；`operational: true`
- 食神：能生财，或能制杀；遇枭印夺食为破格；食神带杀时忌财（财党杀去食）；`operational: true`
- 七杀：身能承受且有食神制杀，或有印化杀；财生杀而无制时不利；`operational: true`
- 伤官：身强时可生财，身弱时可用印制伤；**伤官见官是条件规则，不是一律为忌**——
  原文：“伤官见官，为祸百端，而金水见之，反为秀气……调候为急，权而用之也”（论用神变化），
  编码时必须保留“金水伤官喜见官”分支；`operational: true`
- 阳刃：刃格以官杀制刃为正例（格局逻辑，不是“日主过旺需调节”的旺衰逻辑）；`operational: true`
- 禄劫：喜透官星、或用财而带食伤；`operational: true`
- 格局出现问题时，重点找“救应”，不能只看一个吉神或凶神；`operational: false`（“救应”需按
  论用神成败救应篇逐格枚举后才可执行）。

含“要重新判断”“倾向于”等措辞的条目一律标 `operational: false`，进入 YAML 前必须
补齐可执行分支或降级为 exploratory。

### 3. 评价大运

- 每一步大运必须同时看天干和地支，不能只看一个字；
- 大运能补足用神或去掉主要问题，倾向于有利；
- 大运直接破坏用神、加强主要问题，倾向于不利；
- 原局有救应时，表面不利的大运可能被缓解；
- 命局和大运要一起判断，不能把“好命”或“坏命”单独固定成终身结论。

### 4. 可映射的 Y

候选映射按格局逐条给出，每条须能回查出处（无出处的映射不得进入 P4）：

| 格局/特征 | 候选 Y | 出处状态 |
|---|---|---|
| 正官格 | 职业/官职 | 有原文可引 |
| 财格 | 财富/财务 | 有原文可引 |
| 印格 | 教育、文教类职业 | 待补引文 |
| 食神格 | 寿命 | 待补引文（“食神主寿”出处需核） |
| 七杀格/阳刃格 | 武职、法律/犯罪 | 待补引文 |
| 伤官格 | 文艺/才艺类职业 | 待补引文 |
| 大运流年 | 上述各域的事件时间 | 有原文可引（论行运） |

这只是传统命题的候选映射，不表示已经有预测效力。正式统计时应一条命题对应一个 Y，避免把“贵、富、寿、婚姻好”合成一个结果；禁止“全部格局 → 全部 Y 域”的全集映射。

## 三、《渊海子平》：基础结构—六亲—疾病—岁运

来源：本地 [现代网页文本](../data/processed/canon/yuanhai_ziping_online.txt)。
网页版章节号不稳定且各版本目录差异大，正式提取时按**篇名**（论妻妾、论子息等）定位，
本节表格第一列即为篇名清单。

### 1. 基础判盘顺序

- 以日主作为个人核心；
- 以月令作为季节和旺衰的重要参照；
- 结合四柱中的财、官、印、食、比劫等关系；
- 再看合、冲、刑、害、三合、三会等结构变化；
- 最后结合大运和流年判断时间变化。

### 2. 传统对象到 Y

| 原书专题 | 可记录的现代 Y |
|---|---|
| 六亲总论、论父、论母 | 父母关系、亲属事实、亲属死亡 |
| 论妻妾 | 婚姻、伴侣、离婚、关系持续时间 |
| 论兄弟姐妹 | 手足关系和家庭网络 |
| 论子息 | 子女数量、生育、子女关系 |
| 论性情 | 独立人格量表或职业代理变量，不能用传记形容词直接替代 |
| 论疾病 | 诊断、手术、事故、疾病死亡 |
| 论大运、论太岁 | 首次事件时间、事件次数、状态转移 |

《渊海子平》篇幅大、格局和神煞内容多；第一版只抽取有明确条件和结果的段落，不先把所有神煞都编码。

## 四、《滴天髓阐微》：整体气势—中和—通关—应事

来源：本地 [现代网页文本](../data/processed/canon/ditiansui_online.txt)（由
`process_canon_layers.py` 从 raw JSONL 清洗生成，raw 保持只读）；引用按任铁樵阐微篇名定位。
注意该来源为现代命理网站，文本可靠性低于扫描本，校勘优先级应最高。
文本分三层：经文（原文）、**【原注】**（刘基原注）、【任氏曰】（任铁樵阐微，归评注层）。

### 1. 结构判断

- 先看全局形势，再看单个干支；
- 先判断月令、旺衰、寒暖燥湿，再定取用；
- 区分清浊、真假、隐显、众寡，判断主要力量是否明确；
- 两方冲突时，寻找通关或转化条件；
- 全局形成单一强势且难以逆转时，考虑从局、化局、顺局或反局；
- 不把“某个字出现”直接等同于某种人生结果。

### 2. 应事专题

该版本明确分出夫妻、子女、父母、兄弟、性情、疾病、出身、地位、岁运等专题。工程上应拆成独立 Y：

```text
夫妻 → 婚姻/关系
子女 → 生育/子女
父母/兄弟 → 家庭/亲属
性情 → 人格量表或行为代理
疾病 → 健康事件
出身/地位 → 社会阶层、教育、职业、成就
岁运 → 事件时间和状态变化
```

## 六、统一逻辑格式

每条候选规则后续写成（schema 与实施计划 P2.5 一致，写第一条规则前锁定）：

```yaml
rule_id: ziping_001
school: ziping            # ziping | xuleiwu | ditiansui | qiongtong…（流派，冲突规则分属不同 school）
source_book: 子平真诠
edition: 徐乐吾评注本（民国二十五年）   # 版本，供扫描本校勘对账
source_section: 论用神     # 篇名定位，不用网页章节号或 PDF 页码
quote: >-                  # 原文引文，锚定与审计依据（实施计划关键约束，必填）
  八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉。
text_layer: 原文           # 原文 | 评注 | 现代白话；评注层规则归入对应评注流派
if:
  - 月令十神 == 正官
  - 有财生官 or 有印护官
  - not 官星被冲克
then:
  - 格局: 正官格成立
candidate_y:
  - career
operational: true          # 条件可机器执行才为 true；含"重新判断/倾向于"措辞的必须为 false
rule_status: candidate     # candidate → verified（扫描本核对后）→ preregistered（进入 P4）
```

规则先以 `candidate` 保存；完成扫描核对、不同版本对比和人工审核后置 `verified`，
才允许进入预注册假设。`operational: false` 的规则不得进入 P4。
现代白话只用于生成短句，不作为证据来源；`text_layer: 现代白话` 的条目仅供索引，不入统计。
