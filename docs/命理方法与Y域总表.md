# 命理方法与 Y（因变量）域总表

更新日期：2026-07-31

## 1. 研究口径

这里的“能测算范围”指某一命理体系在传统文献和现代实践中**声称可以讨论的对象**，不等于已经被统计证明有效。研究时必须把它翻译成可观察的 Y（因变量）：事件是否发生、何时发生、发生几次、状态是什么，或者两个人/一个地点之间的关系结果。

不能把“富贵、婚姻好、身体差、命硬”等解释性语言直接当 Y。它们必须先拆成来源可回查的事实或独立量表。

## 2. 统一的 Y 类型

| Y 类型 | 统计形式 | 例子 | 适用方法 |
|---|---|---|---|
| 发生与否 | 二元 `0/1` | 是否结婚、是否入仕、是否患病 | 八字、紫微、占卜、姓名等 |
| 发生时间 | 生存/事件时间 | 首次婚姻年龄、死亡年龄、首次任职年份 | 八字大运流年、紫微限运、占星推运 |
| 重复次数 | 计数/复发事件 | 工作变动次数、疾病次数、迁居次数 | 八字、紫微、占星、事件占卜 |
| 状态类别 | 多分类/序数 | 职业层级、官阶、婚姻状态、宗教身份 | 紫微十二宫、八字十神/格局、CBDB |
| 连续量表 | 连续/标准分 | 人格、幸福感、健康评分、收入 | 性格类命理必须配合独立问卷 |
| 状态转移 | 序列/多状态模型 | 单身→结婚→离婚、学生→任职→退休 | 大运流年、紫微限运 |
| 两人关系 | 配对/二元关系 | 是否结婚、关系持续时间、冲突次数 | 合婚、八字合盘、紫微合盘 |
| 地点/方向结果 | 空间变量 | 迁移方向、居住地、出行是否成功 | 奇门、风水、六壬、择日 |
| 决策结果 | 干预后的成败 | 某日签约是否成功、出行是否顺利 | 奇门、六爻、梅花、择日 |
| 宏观结果 | 时间序列/区域面板 | 战争、灾害、政权变化、经济波动 | 太乙、奇门、六壬等宏观应用 |

## 3. 结果域总目录

这是项目建议使用的统一 Y 目录。它比某一个命理体系的术语更稳定。

| Y 域 | 可观察终点 | 推荐 Y 形式 | 当前资料可得性 |
|---|---|---|---|
| 寿命/死亡 | 死亡、死亡原因、死亡年龄 | 时间到事件、原因分类 | ADB/CBDB 较可用 |
| 婚姻/伴侣 | 初婚、再婚、离婚、关系开始/结束 | 首次时间、重复事件、状态转移 | ADB 较可用 |
| 生育/子女 | 生育、子女数量、子女死亡 | 二元、计数、时间 | CBDB 关系较多，日期不足 |
| 家庭/亲属 | 父母/配偶/子女、亲属死亡、家庭责任变化 | 关系图、事件、计数 | CBDB/ADB |
| 教育/考试 | 入学、毕业、考试、科举、学位 | 事件时间、等级、二元 | CBDB/ADB |
| 职业/官职 | 入职、转职、升迁、失业、退休、官阶 | 事件序列、状态等级 | ADB/CBDB |
| 财富/财务 | 收入、财富变化、投资、破产、财产 | 事件/连续量/等级 | ADB 事件较少，需谨慎 |
| 成就/声望 | 获奖、发表、重大作品、任命、社会地位 | 二元、计数、首次时间 | ADB 较可用 |
| 健康/疾病 | 诊断、手术、事故、慢病、康复、死亡原因 | 二元、时间、复发次数 | ADB 较可用 |
| 心理/行为 | 抑郁、成瘾、人格、暴力、风险行为 | 独立量表、诊断、事件 | 现有档案不足 |
| 法律/犯罪 | 逮捕、审判、犯罪实施/受害、监禁 | 二元、计数、时间 | ADB 可用但选择偏差大 |
| 迁移/旅行 | 迁居、移民、长期居住、旅行 | 空间轨迹、事件时间 | ADB/CBDB，CBDB 籍贯不是迁移 |
| 宗教/身份 | 出家、宗教身份、职业身份、身份转换 | 二元、状态转移 | CBDB/ADB |
| 社会组织 | 入会、退会、机构化、军队/组织经历 | 事件、状态 | ADB 较可用 |
| 住宅/环境 | 房屋、居住环境、地点变化 | 空间与事件 | 需单独收集房屋资料 |
| 人格/才能 | 外向性、领导力、艺术/科学能力 | 独立心理测量、职业代理变量 | 不能直接用传记评价替代 |
| 幸福/满意度 | 主观幸福感、生活满意度、压力 | 独立问卷连续量 | 现有数据库基本没有 |
| 决策/择日 | 签约、考试、出行、手术、交易成败 | 干预结果二元/序数 | 需前瞻性收集 |
| 方向/地点 | 出行方向、目的地、事件地点 | 空间结果 | 需明确问题和时间 |
| 宏观社会 | 战争、灾害、政权、经济 | 时间序列/区域面板 | 不能与个人命盘直接混合 |

## 4. 不同命理体系的声称范围

### 4.1 八字/四柱、子平法

核心对象是出生时刻形成的四柱，以及大运、流年和流月的时间变化。

| 传统讨论对象 | 可操作化 Y |
|---|---|
| 性情、才性、强弱 | 独立人格量表、职业选择、行为事件；不能用命理描述本身作 Y |
| 学业、功名、科举 | 入学、毕业、考试、科举、学位、任命 |
| 官禄、事业 | 入职、职业类别、升迁、转职、退休、社会地位 |
| 财帛 | 收入/资产连续量，或破产、投资、财产事件 |
| 婚姻、妻财、子女 | 初婚、离婚、子女数量、生育时间、家庭关系 |
| 疾病、灾厄、寿夭 | 诊断、手术、事故、死亡及死亡年龄 |
| 迁移、行运 | 迁居、移民、旅行、居住地变化 |
| 大运流年应期 | 首次事件年份、事件密度、状态转移 |

八字最适合测试“出生资料 → 人生事件时间/类别”的关系。它不应在同一个 Y 上同时使用多个互相重叠的“格局解释”，否则会产生多重检验和事后挑规则。

### 4.2 紫微斗数

紫微的天然结构是十二宫，因此可以建立“宫位 → Y 域”的先验映射：

| 宫位 | 主要声称范围 | Y 域 |
|---|---|---|
| 命宫、身宫 | 性格、体质、人生总体 | 人格量表、健康、综合结果；需避免复合 Y |
| 兄弟宫 | 手足关系 | 家庭/亲属 |
| 夫妻宫 | 婚姻、伴侣 | 婚姻/关系 |
| 子女宫 | 子女、生育 | 生育/子女 |
| 财帛宫 | 收入、财富、财务方式 | 财富/财务 |
| 疾厄宫 | 疾病、体质 | 健康/疾病 |
| 迁移宫 | 外出、迁移、外部环境 | 迁移/旅行 |
| 仆役/交友宫 | 社会关系、朋友、合作 | 社会网络/关系 |
| 官禄宫 | 职业、事业、名位 | 职业/成就 |
| 田宅宫 | 房屋、不动产、居住 | 住宅/环境 |
| 福德宫 | 享受、精神状态、幸福感 | 幸福/心理 |
| 父母宫 | 父母、长辈、教育资源 | 家庭/教育 |

紫微的统计单元通常要同时考虑本命盘和限运盘；不能只用“十二宫出现某星”而不固定宫位、四化、排盘历法和大限起法。

### 4.3 西方占星、七政四余

| 传统对象 | Y 域 |
|---|---|
| 本命性格、气质 | 人格量表、兴趣、职业代理指标 |
| 第十宫/中天 | 职业、地位、成就 |
| 第二宫/第八宫 | 收入、资源、共同财务、债务 |
| 第七宫 | 婚姻、伴侣、合作 |
| 第五宫 | 子女、创造、娱乐、作品 |
| 第六宫/第十二宫 | 健康、疾病、机构化 |
| 第四宫 | 家庭、父母、住宅 |
| 第九宫/第三宫 | 高等教育、长途旅行、迁移 |
| 行运、次限、太阳弧 | 事件时间和状态转移 |

西占可与八字共用一套 Y，但排盘特征、时间体系和先验规则必须独立；不能把同一个人同时算作两个方法的独立样本。

### 4.4 六爻、梅花易数、奇门遁甲、大六壬

这些方法更适合“针对某个问题的事件占测”，不是天然的出生档案模型。

| 方法 | 典型问题 | 应使用的 Y |
|---|---|---|
| 六爻 | 婚姻、求财、考试、求职、诉讼、疾病、失物、出行 | 问题是否成功、何时发生、状态变化 |
| 梅花易数 | 即时起卦的事情成败、方向、时间 | 二元成败、方向、时间窗 |
| 奇门遁甲 | 出行、战争、谈判、求职、交易、择时择方 | 决策结果、方向结果、事件时间 |
| 大六壬 | 复杂人事、官讼、疾病、盗失、行旅 | 事件类别、成败、时间、关系角色 |

这类方法需要前瞻性记录：提问时间、问题原文、起局规则、预测内容、截止时间和真实结果。不能拿事后找到的新闻或传记反向起卦。

### 4.5 太乙神数与宏观术数

传统上更偏向战争、政局、灾异、区域和时代变化。研究 Y 应使用：

- 战争是否发生、持续时间、伤亡；
- 政权更迭、重大政治事件；
- 灾害发生、类型、地点和损失；
- 区域经济或人口变化。

这些 Y 属于时间序列或区域面板，不能直接和单个人的八字样本拼接。

### 4.6 风水、阳宅、择日择时

它们的核心解释变量不是出生时间，而是地点、朝向、布局、日期或人为选择。因此应单独设计：

| 方法 | 解释变量 | Y |
|---|---|---|
| 阳宅/风水 | 地址、朝向、布局、环境变化 | 健康、财富、居住稳定、家庭关系 |
| 阴宅 | 墓地位置、家族关系 | 家族事件；需极谨慎，易有混杂 |
| 择日 | 选定日期与未选日期 | 事件成功、损失、恢复时间 |
| 择时/择方 | 时间、方向、行动方案 | 出行、交易、手术、谈判结果 |

若没有同一人的环境变更前后资料，不能把住宅效果归因给风水；若只观察被选中的吉日，也没有未选日期这个对照。

### 4.7 姓名、生肖、属相、合婚

| 方法 | 典型声称 | 可操作化 Y | 主要问题 |
|---|---|---|---|
| 姓名学 | 性格、事业、婚姻、健康 | 人格、职业、婚姻事件 | 年龄、家庭和社会阶层混杂 |
| 生肖/属相 | 性格、婚配、年份运势 | 配对婚姻、职业/健康事件 | 年份与文化 cohort 强混杂 |
| 合婚/合盘 | 关系匹配、婚姻稳定 | 是否结婚、关系持续时间、离婚 | 必须以配对为分析单元 |
| 称骨等简化法 | 综合富贵、寿命、人生等级 | 预先定义的等级或事件复合指标 | 规则粗糙，需单独作为基线 |

### 4.8 面相、手相等体相类

| 方法 | 典型声称 | 解释变量（X） | 研究可行性 |
|---|---|---|---|
| 面相（麻衣神相、柳庄相法等） | 性格、富贵、寿夭、六亲 | 面部特征测量 | 现有数据库无 X；历史画像不可靠，现代照片涉及肖像权与伦理审查 |
| 手相 | 性格、健康、寿命 | 掌纹特征 | 同上 |
| 冰鉴类观人术 | 才能、可用性 | 神态、体貌 | 无法客观测量，仅文献层 |

体相类与风水（X 是环境）、择日（X 是决策）同属"解释变量不在出生档案中"的方法。
文本可以进语料库和规则候选层，但规则一律 `operational: false`；另有一个八字类
没有的混杂：**反向因果**——年龄、营养、疾病、职业风霜都会改变面相，"面相预测
命运"很大程度是读出了已经发生的事。除非单独立项采集体相数据并预注册，否则不进入统计验证。

## 5. 方法与 Y 的推荐匹配

| 方法 | 最适合的 Y | 不宜直接声称的 Y |
|---|---|---|
| 八字 | 个人事件时间、职业/婚姻/健康/寿命、状态转移 | 绝对财富、人格本质、精确死亡日 |
| 紫微 | 十二宫对应的个人状态与事件 | 不固定排盘规则的综合吉凶 |
| 西占/七政 | 本命性格代理、关系、职业、行运时间 | 单一星体直接决定具体事件 |
| 六爻/梅花 | 单问题成败、时间窗、方向 | 从出生盘推一生全部结果 |
| 奇门/六壬 | 决策、出行、谈判、诉讼等事件 | 无问题文本的泛化人格结论 |
| 太乙 | 宏观战争、灾异、政局时间序列 | 个人职业/婚姻 |
| 风水 | 环境变更前后的居住与家庭结果 | 脱离地址和环境测量的个人命运 |
| 择日择时 | 选定行动的结果 | 把选择后的结果当自然预测能力 |
| 姓名/生肖 | 配对或 cohort 基线 | 复杂个人事件的强因果结论 |

## 6. 进入本项目的优先级

### P0：现有数据库可以直接做

- 寿命/死亡；
- 婚姻/关系变化；
- 教育/科举；
- 职业/官职；
- 健康/疾病/事故；
- 迁移/居住；
- 成就/声望；
- 法律/犯罪；
- 家庭/亲属。

### P1：补充资料后再做

- 财富/收入；
- 心理健康；
- 人格与才能；
- 幸福感；
- 住宅/风水；
- 合婚和配对。

### P2：需要另建前瞻性实验

- 六爻、梅花、奇门、大六壬的单问题预测；
- 择日择时；
- 方向/地点预测；
- 太乙等宏观术数。

## 7. 项目中的实际约束

1. 一个命理方法可以映射到多个 Y，但每个 Y 必须独立定义纳入条件、时间窗、日期精度和缺失机制。
2. 一个 Y 可以由多个方法预测，但方法特征要分列，并进行多重检验和基线比较。
3. “没有记载”不是“没有发生”；当前 `person_prediction_outcomes` 只保存来源证据支持的阳性观察。
4. 传记中“富贵、聪明、婚姻幸福”等评价不能直接入库为 Y，除非有独立、可重复的编码规则和证据。
5. 传统体系的预测范围是研究假设来源，不是结果本身；最终只能由预注册分析、对照实验和外部验证判断是否有超出基线的预测信息。
