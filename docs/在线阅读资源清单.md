# 命理古籍在线阅读资源清单

更新日期：2026-07-31

## 1. 推荐入口

### A 级：用于版本和原文核对

- [维基文库：《三命通会》](https://zh.wikisource.org/zh-hans/%E4%B8%89%E5%91%BD%E9%80%9A%E4%BC%9A)：有卷一至卷九的可检索文字，页面明确说明卷十至卷十二缺失；适合阅读和引用网页章节，但关键句仍回看扫描本。
- [中国哲学书电子化计划：原典检索](https://ctext.org/searchbooks.pl?if=gb&remap=gb)：可检索大量古籍和部分命理文献；网站也提供电子图书馆影印本入口。部分页面存在访问限制，适合浏览和查版本，不把抓取失败当作文本不存在。
- [中华文库：《三命通会》四库全书本](https://www.zhonghuashu.com/wiki/%E4%B8%89%E5%91%BD%E9%80%9A%E4%BC%9A)：可按卷阅读四库本文字，适合与明刻扫描本进行异文对照。

### B 级：原文与白话辅助阅读

- [古籍典藏：《渊海子平》](https://www.luckclub.cn/bazi/001/)：目录完整，页面标注原文和白话译文；适合快速定位章节，不作为唯一底本。
- [古籍典藏：《子平真诠》](https://www.luckclub.cn/bazi/002/)：现代网页整理/评注，适合入门和检索。
- [古籍典藏：《滴天髓阐微》](https://www.luckclub.cn/bazi/007/002/)：有“原文/白话译文”切换，适合先理解任铁樵注本的结构。
- [古籍典藏：《三命通会》](https://www.luckclub.cn/bazi/005/)：适合按专题浏览，但应核对其底本和现代解释。

### C 级：现代解释或专题文章

- [豆瓣阅读：《穷通宝鉴》白话详解](https://read.douban.com/column/7731974/)：页面明确采用“原文 + 徐乐吾 + 诠释”的结构，适合了解解释层，不宜直接当作原文。
- [古籍典藏《渊海子平》章节页](https://www.luckclub.cn/bazi/001/292/)：可作为单章检索入口，例如“明通赋”。

## 2. 怎样使用这些网站

对任何一句候选规则，按以下顺序处理：

```text
在线网页定位 → 记录书名/卷/章 → 回看本地扫描页 → 对比至少一个版本
→ 分离原文与评注 → 再操作化为八字特征和 Y
```

网页的现代标点和白话译文不能直接写入 `canon_claims.quote`。应分别保存：

- `quote_original`：原文；
- `punctuated_text`：点校断句；
- `translation`：白话译文；
- `commentary`：评注；
- `source_url`：网页地址；
- `scan_page`：本地扫描页码；
- `edition`：底本或网页版本说明。

## 3. 当前最实用的阅读组合

如果目标是先理解八字的规则结构，可以这样组合：

1. 在线看《渊海子平》目录和白话，建立基础术语；
2. 在线看《子平真诠》用神、格局、成败章节；
3. 用《三命通会》四库本查同一概念的扩展和命例；
4. 用《滴天髓阐微》理解理法类解释；
5. 回到本地 `data/raw/canon/wikimedia/` 扫描本确认原文；
6. 只有通过版本核对的内容，才进入规则表。

## 4. 可靠性边界

在线网站的存在不代表内容已被校勘。尤其要注意：

- 现代网站可能将原文、古注、近代评注和网站作者解释连续排版；
- 《穷通宝鉴》有《栏江网》、余春台整理本及近现代评注等不同层次；
- 《滴天髓》作者、原注和后世注本的归属有版本问题；
- 《三命通会》网页版本可能只覆盖部分卷次；
- 白话解释出现“准确率”“验证有效”等判断时，应视为作者意见，不作为研究结论。
