# 濒死探索方案（第二研究层）

更新日期：2026-08-03

## 定位

项目分两个研究层，导航与数据完全独立：

1. **玄学命理**——出生资料 → 命理体系 → 统计验证（现有主线）；
2. **濒死探索**——濒死体验（NDE）案例库，目标是**按现象分类**，每个大类索引到具体案例。

两层暂不交叉；未来若做交叉分析（如体验内容与文化背景的关系），另行设计。

## 数据源与采集

- 来源：NDERF（nderf.org）公开案例，约 5800 篇（1998–2026 年归档 + 当前页 + 精选页）。
- `download_nderf.py --stage index`：抓归档列表，生成案例 URL 清单；
- `download_nderf.py --stage pages`：逐篇抓原始 HTML（0.6s 间隔礼貌抓取，
  JSONL 按年分片，断点续抓），落 `data/raw/nderf/`。
- 仅作本地研究快照，不对外分发；每篇保留 sha256 与抓取时间。

## 解析与现象分类

- `parse_nderf.py`：原始 HTML → `data/processed/nderf/experiences.jsonl`，
  每篇含标题、NDERF 分类（NDE/Probable NDE 等）、叙述正文、标准化问卷（问题→答案）。
- **分类依据是问卷答案，不是对叙述文本的关键词猜测**。NDERF 每篇案例自带标准化
  问卷（"是否穿过隧道""是否见到强光""是否遇到已故者"…），
  `numerology/nde/phenomena.yaml` 把每个现象大类映射到问卷问题与答案判定规则；
  每个命中的类别都保留证据答案，可回查原文。
- **三层抽象**（由可复现 → 可发现）：
  1. **问卷现象** `phenomena.yaml`：NDERF 标准问答题 → 高可统计（灵魂出体、隧道、强光…及扩展的平静/喜悦/难以言表/远程觉知等）
  2. **正文母题** `motifs.yaml`：叙述关键词（白光、音乐、光之城、返回抉择…）→ 自动挖掘细粒度母题，默认 candidate
  3. **理念概念** `concepts.yaml`：世界观理解（时间虚幻、一体、光即存有…）→ 模型标注
- 问卷有新旧版本，问法不同；分类规则按实际问题文本的变体逐步补齐。
  - 规则改动后：若 raw 未变，优先 `python3 reclassify_nde.py`（只刷新 `categories`）；
    加 `--motifs` 同时重标正文母题。
  - 否定应答（No / Uncertain / None…）**词边界优先**于 `positive_contains`，
    避免 “No, I did not acquire…” 误阳；也不把 “no longer” 当否定。
  - 部分 NDERF 答案形如 “No I clearly left my body…”（选项是否定、后附模板句），
    按问卷纪律记为阴性。
  - **自动挖更多现象**：
    ```bash
    python3 -m scripts.nde.mine_nde_phenomena
    # → data/audits/nde_phenomena_mine_latest.json
    # 确认后写入 phenomena.yaml / motifs.yaml，再 reclassify
    python3 reclassify_nde.py --motifs
    ```
  - 质量审计：`python3 audit_corpus_mapping.py` → `/quality` 顶部摘要。
  - 中文证据圈注补缺：
    ```bash
    python3 map_evidence_zh.py --mode missing --dry-run
    python3 map_evidence_zh.py --mode all_gaps --limit 50
    python3 map_evidence_zh.py --compact   # 压实追加式 jsonl
    ```

## 网页

- `/nde`：现象大类卡片（含案例数）+ NDERF 分类分布；
- `/nde/category/<key>`：大类下的案例列表（标题、问卷证据、叙述摘要）；
- `/nde/experience/<slug>`：单篇案例——叙述原文 + 完整问卷 + 现象标签 + 原站链接。

## 翻译

- 数据模型已预留 `translations`（语言→译文），译文生成后与原文并排显示在案例页；
- 译文计划用模型生成（同 `translate_bio.py` 模式），标注"机器生成"；
  优先翻译精选案例（exceptional 列表）与各大类的代表案例，不做全量（成本考虑）。
