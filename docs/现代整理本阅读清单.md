# 现代整理本阅读清单

更新日期：2026-07-31

## 1. 推荐原则

现代版本可以解决繁体、无标点和阅读门槛，但不能自动解决“解释是否正确”。本项目采用三层材料：

```text
扫描原本       = 版本与原文证据
现代点校/白话   = 阅读和检索辅助
现代研究/评注   = 独立解释层，不直接当作古籍原义
```

现代书籍有版权，项目不下载未经授权的 PDF；建议购买正版或通过图书馆借阅。古籍扫描本与现代评注本不能混为一个文本版本。

## 2. 可优先购买或借阅的版本

| 书 | 现代版本 | 用途 | 研究注意 |
|---|---|---|---|
| 《三命通会》 | 中医古籍出版社，2008，ISBN `9787801746634`，上下册 | 目前最适合先查阅的足本，点校并附白话释意 | 仍应回看四库本或明刻本；全书内容庞杂，不宜直接当单一流派 |
| 《子平真诠评注》 | 中州古籍出版社，1994，徐乐吾评注、孙正治点校，ISBN `7534812720` | 适合快速理解用神、格局和成败救应 | “原著”和徐乐吾评注必须分栏；评注是民国解释，不等于沈孝瞻原意 |
| 《子平真诠》 | 西藏藏文古籍出版社，2014，徐乐吾评注，ISBN `9787805892672` | 较容易购买的现代排印本 | 仍然是评注本，不是纯原文 |
| 《穷通宝鉴评注》 | 中医古籍出版社，2012，孙正治注译，ISBN `9787515201375` | 原文、评注、今译对照，适合检索调候思想 | 《穷通宝鉴》本身是整理归纳后的版本，不能与更早的《栏江网》简单等同 |

## 3. 推荐阅读顺序

### 只想先看懂体系

1. 《图解三命通会》：建立术语地图；
2. 《子平真诠评注》：理解月令、用神和格局；
3. 《滴天髓征义》：理解理法和气势类解释；
4. 《穷通宝鉴评注》：单独研究调候，不与其他流派混成一套；
5. 回到项目保存的扫描本逐句核对。

### 项目要提取可检验规则

不要按“入门顺序”直接写规则，而按以下顺序建立证据：

1. 从扫描本定位原文页码；
2. 用点校本确认断句和异体字；
3. 把现代评注单独存储；
4. 比较不同注家是否给出不同解释；
5. 把原文命题翻译为明确的八字特征和 Y；
6. 经过人工审核后才写入 `canon/hypotheses.yaml`。

## 4. 为什么不能只读现代白话版

现代版本常会做以下处理：

- 合并异文；
- 替古字、补标点；
- 用现代术语解释五行、格局和用神；
- 把多个注家意见合并成一段；
- 删除重复歌诀、命例或版本说明。

这些处理对学习很有帮助，但会影响规则研究。例如“用神”在不同书和不同注家中可能不是同一个操作定义；如果只保留白话结论，就无法判断规则到底来自原书、评注者，还是现代编者。

## 5. 项目中的存储建议

以后新增 `canon_texts` 和 `canon_claims` 时，至少保留：

```text
canon_texts:
  text_id, book, edition, author_claimed, publication_year,
  volume, page, scan_path, source_url, sha1

canon_claims:
  claim_id, text_id, quote, normalized_quote,
  commentator, interpretation, school,
  operational_feature, operational_y,
  source_status, review_status
```

其中：

- `quote` 是扫描/点校原文；
- `interpretation` 是评注或白话解释；
- `operational_feature` 是八字特征；
- `operational_y` 是统计因变量；
- `source_status` 区分原文、古注、近代注、现代解释；
- `review_status` 未通过人工核对时不能进入正式分析。
