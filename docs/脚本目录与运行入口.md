# 脚本目录与运行入口

项目脚本已按职责分层，详细映射见 [`scripts/README.md`](../scripts/README.md)。

常用入口：

```bash
# 人物数据
python3 -m scripts.collectors.collect_adb --limit 1000
python3 -m scripts.collectors.collect_wikidata --start-year 1900 --end-year 1950

# 古籍与 OCR
python3 -m scripts.canon.download_canon_web --help
python3 -m scripts.canon.ocr_canon --help
python3 -m scripts.canon.process_canon_layers
python3 -m scripts.canon.translate_huayan_segments --list-missing

# 濒死体验
python3 -m scripts.collectors.download_nderf --help
python3 -m scripts.nde.parse_nderf
python3 -m scripts.nde.reclassify_nde

# 审计与研究口径
python3 -m scripts.quality.audit_data --persist
python3 -m scripts.quality.audit_corpus_mapping
python3 -m scripts.analysis.standardize_prediction_domains
```

旧的 `python3 xxx.py` 入口暂时保留为兼容层，只负责转发到 `scripts/` 中的实现；不要在根目录
新增同类脚本。`server.py` 仍是根目录应用入口。
